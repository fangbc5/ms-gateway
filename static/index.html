Core Features

Production-ready capabilities for modern microservice architectures

🔀

Dynamic Routing

Wildcard and path-variable patterns with pre-compiled regex. Hot-reload via file watcher or POST /_reload.

⚡

Load Balancing

Round-robin, weighted random, and consistent IP-hash strategies. Pluggable, per-route configurable.

🔐

JWT Authentication

Automatic token validation with configurable whitelist bypass. Pre-constructed decoding key for zero overhead.

🩺

Health Checks

Active upstream probing with configurable thresholds. Auto-remove unhealthy nodes, auto-recover when healthy.

🌐

Nacos Integration

Pluggable service discovery and config center. Subscribe to instance changes, dynamic upstream resolution.

📊

Prometheus Metrics

Request count, latency histograms, and status code breakdowns. Template-based labels prevent cardinality explosion.

🚦

Rate Limiting

Global QPS cap + per-client rate limiting powered by Governor. Protects upstream services from overload.

🔌

WebSocket Proxy

Transparent WebSocket upgrade and bidirectional pass-through. Full HTTP/1.1 101 handshake support.

🌊

Streaming Body

Zero-copy streaming request/response forwarding. No full-body buffering — ideal for large payloads.

Quick Start

Get your gateway running in seconds

terminal
# Clone the repository $ git clone https://github.com/fangbc5/ms-gateway.git $ cd ms-gateway # Configure your environment $ cp .env.example .env $ vim .env # edit JWT key, QPS, etc. # Run the gateway $ cargo run --release 🚀 Gateway listening on http://0.0.0.0:8080
